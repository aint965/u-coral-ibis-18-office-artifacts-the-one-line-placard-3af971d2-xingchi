# Office Artifacts: The One-Line Placard

A one-line museum placard for an ordinary office object — a hole punch —
written as if it were an ancient artifact dug from a lost civilisation.
The program writes exactly one line to `/output/entry.txt`.

## Run

```sh
node main.ts
```

Writes the placard to `/output/entry.txt` (or to `$OUTPUT_DIR/entry.txt`
when that variable is set, for local runs).
